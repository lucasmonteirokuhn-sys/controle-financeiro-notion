# 💳 Controle Financeiro Pessoal | Notion

## 📌 Sobre o projeto

Sistema de controle financeiro pessoal desenvolvido no Notion,
com foco na organização de receitas, despesas, planejamento
mensal e acompanhamento de indicadores financeiros.

## 🎯 Funcionalidades

- Registro de receitas e despesas.
- Controle de transações financeiras.
- Consolidação do orçamento mensal.
- Cálculo automático do saldo realizado.
- Definição de metas de reserva.
- Cobertura da meta de reserva.
- Indicador de renda comprometida.

## 🛠️ Tecnologias e recursos

- Notion
- Modelagem de dados relacionais
- Relations
- Rollups
- Fórmulas condicionais
- Indicadores financeiros (KPIs)
- Markdown

## 🗂️ Estrutura do projeto

| Módulo | Finalidade |
|---|---|
| Transações financeiras | Registro das movimentações |
| Orçamento mensal | Consolidação dos valores mensais |
| Resumo financeiro | Acompanhamento dos indicadores |

## 📊 Regras de negócio

- Saldo realizado = Receitas - Despesas
- Cobertura da meta = (Saldo / Meta de reserva) × 100
- Renda comprometida = (Despesas / Receitas) × 100

## 🚀 Objetivo

Aplicar conceitos de modelagem de dados, automação
de cálculos, organização de informações e construção
de indicadores gerenciais em uma solução prática.

## 🔒 Privacidade

Os dados financeiros utilizados para demonstração
do projeto são fictícios.
